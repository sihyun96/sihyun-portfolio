04 problems & solutions

hover 기반 인터랙션 모바일에서는 어떻게 처리할까

PC에서는 hover 인터랙션으로 콘텐츠 노출
모바일 환경에서는 hover 이벤트 없음
주요 정보가 사용자에게 노출되지 않는 문제 발생

-> hover → click / touch 이벤트로 변경
-> 기본 상태에서 핵심 콘텐츠 일부 노출
-> active 클래스 토글 방식으로 상태 관리
-> 디바이스 분기 처리 (media query or JS)
-> UX 기준으로 인터랙션 최소화 및 직관성 개선

반응형에서 레이아웃 깨짐 없이 유지할 수 있을까

PC 기준 디자인 그대로 축소 시 콘텐츠 겹침 발생
텍스트 및 이미지 비율 불균형
섹션 간 간격 깨짐

-> 브레이크포인트별 레이아웃 재설계
-> clamp() 활용한 유동적인 폰트 사이즈 적용
-> 이미지 비율 유지 (object-fit 활용)
-> padding / margin 재정의로 간격 균형 유지
-> 콘텐츠 중요도 기준으로 순서 재배치

포트폴리오 콘텐츠 가독성을 어떻게 높일까

이미지 중심 UI로 텍스트 가독성 저하
다양한 프로젝트가 나열되면서 시선 분산 발생

-> 타이포그래피 대비 강화 (font-weight, size 조정)
-> 카드 UI 구조로 콘텐츠 그룹화
-> hover 시 추가 정보 노출 방식 적용
-> 시선 흐름 고려한 레이아웃 구성 (Z-pattern)
-> 여백을 활용한 콘텐츠 분리

04 result

review

본 프로젝트를 통해 단순히 디자인을 코드로 구현하는 수준을 넘어, 사용자 경험을 고려한 퍼블리싱 역량을 강화했다. 특히 에이전시 홈페이지 특성상 브랜드 이미지와 신뢰도를 동시에 전달해야 했기 때문에, 시각적 완성도뿐 아니라 정보 전달 구조에 대한 고민이 필수적이었다. 이에 따라 각 섹션의 콘텐츠 우선순위를 재정의하고, 사용자 시선 흐름을 기반으로 레이아웃을 설계하는 방식으로 접근했다.

퍼블리싱 과정에서는 PC 중심의 인터랙션이 모바일 환경에서 동일하게 작동하지 않는 문제를 직접 경험하며, 디바이스별 UX 차이를 실질적으로 이해하게 되었다. 단순히 hover를 제거하는 방식이 아닌, 터치 기반 인터랙션으로 재설계하고 기본 상태에서도 핵심 정보가 노출되도록 구조를 개선했다. 이를 통해 다양한 환경에서도 일관된 경험을 제공하는 반응형 설계 역량을 확보했다.

또한 반응형 작업 시 단순 비율 축소가 아닌, 레이아웃 자체를 재구성하는 방식으로 접근하여 콘텐츠의 가독성과 전달력을 유지하는 데 집중했다. clamp()를 활용한 유동적인 타이포그래피 설정과 이미지 비율 유지 처리 등을 적용하여 퍼블리싱 완성도를 높였다. 이 과정에서 디자인 의도를 해석하고 이를 코드 구조로 변환하는 능력이 향상되었으며, 유지보수와 확장성을 고려한 클래스 설계 및 컴포넌트화 작업을 통해 프론트엔드 개발로 확장 가능한 기반을 구축했다.

결과적으로 본 프로젝트는 퍼블리셔로서의 구현 능력뿐 아니라, UX 관점에서 문제를 정의하고 해결하는 사고력을 동시에 강화한 작업이었다.
